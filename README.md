# Anthem Madness by adjiebrotot

Free sheet music (PDF) and MIDI of national anthems in full orchestral arrangements, at
[anthem.adjiebrotots.com](https://anthem.adjiebrotots.com/).

- `docs/` is the published site (GitHub Pages: branch `main`, folder `/docs`, custom domain anthem.adjiebrotots.com).
- `build/` generates it from an [anthem-orchestra](https://github.com/adjiebrotot/anthem-orchestra) checkout.
  How to rebuild and add anthems: [CLAUDE.md](CLAUDE.md).
